## Endpoints, parámetros de ruta y consulta

En estos ejercicios se aprende a crear **endpoints en Express.js** utilizando el método `GET`, recibir información enviada por el cliente mediante **parámetros de ruta (`req.params`)** y **parámetros de consulta (`req.query`)**, y devolver una respuesta al cliente utilizando **`res.status()`** y **`res.json()`**.

Los parámetros de ruta permiten identificar un recurso específico, por ejemplo, un usuario mediante su ID. Los parámetros de consulta permiten enviar filtros o información adicional, como un estado, nombre o especie.

Estos ejercicios permiten comprender el funcionamiento básico de una **API REST**, donde el cliente realiza una petición al servidor, Express procesa los datos recibidos y el servidor devuelve una respuesta en formato **JSON** acompañada de un código de estado HTTP.
